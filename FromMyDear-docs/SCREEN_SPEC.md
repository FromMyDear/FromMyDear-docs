## 정보 구조

하단 탭: 오늘 / 일정 / 함께 / 기록. 프로필·설정은 오늘 탭 상단에서 진입.

| 탭 | 주요 내용 |
| --- | --- |
| 오늘 | 영상 타임라인, 오늘의 공동 일정, 촬영 진입 |
| 일정 | 하루 일정, 월간 캘린더, 여행 |
| 함께 | 장보기, 공동 할 일, 준비물 |
| 기록 | 일기, 문장·단어, 날짜별 영상 모음 |
