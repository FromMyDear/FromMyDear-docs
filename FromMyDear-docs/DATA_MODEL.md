# 데이터 모델

> 상태: 초안 뼈대. 확정된 테이블은 Server 레포의 Flyway 마이그레이션(V2~)으로 반영한다.

## 공통 규칙

- 기본 키: UUID
- 시각: `timestamptz`(UTC). 종일 일정 날짜는 `date`
- 사용자 시간대: IANA 이름(`Asia/Seoul`)을 사용자 설정에 별도 저장
- 생성·수정 시각: `created_at`, `updated_at`
- 동시 수정이 필요한 테이블: `version` 컬럼(낙관적 잠금)

## 엔터티 목록

| 엔터티 | 설명 | 소유자 |
| --- | --- | --- |
| user | 계정 | 본인 |
