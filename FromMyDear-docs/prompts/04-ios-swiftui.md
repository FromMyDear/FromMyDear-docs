# SwiftUI 프론트엔드 개발용 프롬프트

너는 숙련된 iOS 엔지니어다.
첨부된 PRD, 화면 명세, 디자인 시스템, API 계약을 기준으로
연인 두 사람 전용 앱 ‘사이’의 SwiftUI 프론트엔드를 구현해라.

설명이나 코드 예시만 제시하지 말고 현재 저장소를 확인한 후
실제 프로젝트 파일을 작성하고 빌드 가능한 상태로 만들어라.

[작업 시작]
- 저장소의 지침과 기존 구조를 먼저 확인해라.
- 기존 코드와 사용자 변경 사항을 보존해라.
- 새 프로젝트라면 지원 iOS 버전과 도구 버전을 확인하고 선택 근거를 기록해라.
- 전달받은 문서가 충돌하면 충돌 내용을 명시하고 API·제품 규칙을 임의로 바꾸지 마라.
- 백엔드가 준비되지 않았으면 동일한 인터페이스의 Mock 서비스를 사용해라.

[기술 방향]
- Swift + SwiftUI
- 기능 단위 폴더 구조
- 화면 상태와 비즈니스 로직을 View에서 분리
- 구조화된 동시성과 async/await 사용
- URLSession 기반 네트워크 계층
- 인증 정보는 Keychain에 저장
- 촬영·미디어 선택·재생은 적합한 Apple 프레임워크 사용
- 불필요한 외부 라이브러리와 과도한 추상화 금지
- UI 상태 갱신의 실행 컨텍스트와 작업 취소를 명확히 관리
- 비공개 사용자 데이터를 운영 로그에 출력하지 않기

[화면]
1. 시작·로그인
2. 연결 전 홈, 초대코드 생성·입력·상대 확인
3. 오늘: 영상 타임라인, 오늘 일정
4. 영상 촬영·선택, 미리보기, 캡션, 업로드 진행·재시도
5. 영상 상세, 댓글·반응
6. 일정: 월간 캘린더, 하루 목록, 생성·수정
7. 여행 상세: 날짜별 일정과 준비물
8. 함께: 장보기·공동 할 일 목록과 항목 편집
9. 기록: 일기·문장 목록, 상세, 작성·수정, 공개 설정
10. 설정: 알림 유형, 요일별 무음 시간, 연결 해제, 계정 삭제

[UX 요구사항]
- 하단 탭: 오늘 / 일정 / 함께 / 기록
- 기록을 공유할 대상과 공개 범위를 저장 전에 명확히 표시
- 일기는 기본 비공개
- 영상 자동 재생은 한 번에 하나만 수행하고 화면 이탈 시 중지
- 영상 음소거 상태를 명확히 표시
- 업로드 중 중복 제출 방지
- 업로드 실패 시 입력 내용 보존 및 재시도
- 목록 체크는 즉시 반영하되 서버 실패 시 복구와 안내
- 오프라인 상태를 명확히 표시하고 미지원 작업을 성공한 것처럼 보이지 않게 처리
- 인증 만료, 연결 해제, 접근 권한 변경에 대응
- 로그아웃·연결 해제 시 관련 캐시와 화면 상태 정리
- 빈 상태, 로딩, 오류, 권한 거절, 재시도 화면 제공
- Dynamic Type, VoiceOver, 다크 모드, 충분한 터치 영역 지원
- 사진·카메라·마이크 권한은 해당 기능 진입 시 요청

[API 연동]
- API_CONTRACT.md의 필드, 날짜 형식, 오류 코드, 페이지네이션을 준수
- 서버 DTO와 화면 모델을 필요에 따라 분리
- 인증 갱신 요청이 동시에 중복 실행되지 않도록 처리
- 서버에서 받은 미디어 업로드 URL로 파일 업로드
- 업로드 완료와 미디어 처리 완료 상태를 구분
- 모든 기록의 접근 권한은 서버 판단을 기준으로 처리
- Mock과 실제 API 구현을 설정으로 교체 가능하게 구성
- 커플 연결·공개 범위 검증을 클라이언트만으로 해결하지 마라.

[구현 순서]
1. 프로젝트 기반, 디자인 토큰, 내비게이션, Mock 데이터
2. 인증과 커플 연결
3. 영상 업로드부터 타임라인 재생까지의 전체 흐름
4. 일정과 공동 목록
5. 여행, 일기, 문장
6. 알림 설정, 연결 해제, 오류·접근성 보완

각 단계마다 빌드하고 핵심 흐름을 확인한 뒤 다음 단계로 진행해라.
개발 중 새로운 계약이 필요하면 API_CONTRACT.md에 제안 내용을 남겨라.

[검증 및 납품]
- 핵심 상태 전이, 공개 범위 UI, 자정 넘는 무음 시간에 의미 있는 테스트 작성
- 실행 가능한 환경에서 빌드·테스트
- 실행하지 못한 검증은 명확히 표시
- README에 실행 방법, 환경 설정, Mock 전환법, 남은 작업 기록
- 비밀키·토큰을 저장소에 넣지 마라.
- 마지막에 구현된 기능, 검증 결과, 실제 연동이 필요한 항목을 간결하게 보고해라.
