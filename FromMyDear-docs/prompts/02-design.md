# 디자인용 프롬프트

너는 iOS 프로덕트 디자이너다.
첨부된 PRD와 화면 명세를 바탕으로 연인 두 사람 전용 앱
‘사이’의 디자인 시스템과 고해상도 화면 시안을 만들어라.

[제품]
서로의 짧은 일상 영상을 공유하고, 일정·장보기·여행을 준비하며,
일기와 좋아하는 문장을 남기는 비공개 커플 앱이다.

[디자인 방향]
- 따뜻하고 차분하며 오래 사용해도 질리지 않는 분위기
- 사진과 영상, 사용자의 글이 중심이 되는 화면
- 과도한 하트, 캐릭터, 핑크색 장식은 피하기
- 셋로그의 일상 공유 맥락은 참고하되 화면·아이콘·브랜딩을 복제하지 않기
- iOS 기본 사용 경험과 잘 맞는 내비게이션·시트·입력 방식
- 과도한 카드 중첩과 장식용 그라데이션 피하기
- 기능과 실제 데이터에 근거한 화면 구성

[시각 스타일 초안]
- 배경: 따뜻한 아이보리
- 본문: 짙은 차콜
- 강조: 차분한 코랄
- 보조: 세이지 계열
- 오류·완료·주의 상태는 서로 구별되는 의미 색상 사용
- 색상은 최종적으로 접근성 대비를 검증해 결정
- 시스템 글꼴 기반의 명확한 타이포그래피
- SF Symbols 중심의 일관된 아이콘
- 여백, 모서리, 구분선, 높이, 터치 영역을 토큰으로 정의
- 다크 모드는 별도 의미 색상으로 설계

[탭 구조]
1. 오늘
- 두 사람의 일상 영상이 가장 중요하게 보이게 구성
- 오늘 날짜와 작은 공동 일정 요약
- 시간순 영상 목록: 작성자, 시간, 캡션, 반응
- 쉽게 찾을 수 있는 촬영 진입점

2. 일정
- 월간 캘린더와 선택한 날짜의 일정
- 나의 일정, 상대가 공유한 일정, 공동 일정 구분
- 색상 외에도 텍스트·아이콘으로 구분
- 여행과 기념일 진입

3. 함께
- 장보기, 공동 할 일, 여행 준비물
- 빠른 항목 추가와 한 손 체크
- 수량과 담당자는 필요한 경우에만 표시
- 완료한 항목의 시각적 우선순위 낮추기

4. 기록
- 일기 / 문장·단어 / 영상 모아보기
- 일기의 공개 범위를 명확하게 표시
- 긴 글과 책 구절의 읽기 편한 타이포그래피

[필수 시안]
- 시작·로그인
- 연결 전 홈
- 초대코드 생성·입력
- 상대 확인과 연결 완료
- 오늘 타임라인
- 영상 촬영·선택
- 업로드 전 미리보기·캡션
- 영상 상세·댓글
- 월간 캘린더·하루 일정
- 일정 생성·수정
- 장보기 목록
- 여행 상세·준비물
- 일기 목록·작성·상세
- 문장·단어 저장·상세
- 알림 설정·무음 시간 편집
- 연결 해제 안내

[상태 설계]
다음을 주요 화면에 적용해라.
- 첫 사용과 빈 상태
- 로딩
- 네트워크 오류와 재시도
- 영상 업로드 진행·실패
- 카메라·마이크·사진 권한 거절
- 초대코드 만료
- 상대 연결 대기
- 연결 해제와 접근 불가
- 입력 오류와 저장 중 상태

[문구와 상호작용]
- 한국어 실제 문구 사용
- 짧고 다정하지만 유아적이지 않은 말투
- 기록을 올리도록 죄책감이나 압박을 주는 문구 금지
- 비공개와 상대 공개를 아이콘만으로 표현하지 않기
- 공개 변경과 연결 해제의 결과를 구체적으로 안내
- 업로드 실패 시 작성 내용이 유지된다는 점 안내
- 키보드, 안전 영역, 스크롤, 긴 캡션, 큰 글자 설정 고려
- 모션 감소 설정과 VoiceOver 읽기 순서 고려

[산출물]
1. 디자인 방향과 선택 이유
2. 색상·타이포·간격·모서리·컴포넌트 토큰
3. 핵심 화면 시안
4. 화면 이동과 주요 상호작용
5. 컴포넌트별 기본·선택·비활성·로딩·오류 상태
6. SwiftUI 구현자를 위한 레이아웃·동작 명세
7. 재사용할 에셋 목록과 내보내기 규격

도구로 실제 시안 제작이 가능하면 시안을 제작해라.
불가능하면 제작한 것처럼 말하지 말고, 바로 구현할 수 있는
화면별 상세 명세를 제공해라.
