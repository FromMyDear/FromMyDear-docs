# 기획(PM·아키텍트)용 프롬프트

너는 모바일 서비스 PM이자 소프트웨어 아키텍트다.
아래 요구사항을 바탕으로 실제 개발에 사용할 수 있는 iOS 앱의 MVP 기획서를 작성해라.

[프로젝트 개요]
- 가칭: 사이
- 연인 두 사람만 사용하는 비공개 일상 공유 앱
- 핵심 가치: 떨어져 있어도 서로의 하루를 나누고, 함께할 일상을 준비하고, 추억을 남긴다.
- 셋로그(setlog)의 일상 영상 공유 경험을 참고하되, 고유한 화면과 디자인을 만든다.
- 다른 앱의 기능을 확인하지 않고 사실처럼 단정하지 마라.
- iOS 프론트엔드: SwiftUI
- 백엔드: Spring Boot + Java
- 데이터베이스: PostgreSQL
- 사진·영상: 비공개 객체 스토리지
- 푸시 알림: APNs
- 공개 피드, 친구 그룹, 다인 초대는 없다.

[사용자와 연결]
- 각자 독립적인 계정을 가진다.
- 한 계정은 동시에 하나의 활성 커플 공간에만 참여할 수 있다.
- 커플 공간은 최대 두 명이다.
- 초대코드 입력 후 양측 확인을 거쳐 연결된다.
- 초대코드는 만료, 재발급, 취소가 가능하다.
- 연결 전에도 개인 일기와 문장 수집을 사용할 수 있다.
- 연결 해제는 한쪽의 요청으로 가능하며, 상대의 승인을 강제하지 않는다.
- 연결 해제 후 이전 상대에게 새로운 기록이 노출되면 안 된다.
- 이전 커플 공간의 기록이 새로운 커플 공간으로 자동 이전되면 안 된다.
- 개인 기록과 공동 기록의 소유권, 연결 해제 후 접근 범위, 삭제 기준을 명확히 정의해라.

[핵심 기능]
1. 일상 영상
- 짧은 영상 촬영 또는 보관함 선택
- 캡션 입력, 업로드, 재생
- 두 사람의 영상을 시간순으로 표시
- 댓글과 이모지 반응
- 날짜별 모아보기
- MVP에서는 자동 편집 영상 생성 없이 날짜별 연속 감상으로 구현
- 영상 길이, 크기, 압축, 보관 정책은 합리적인 초안을 제안

2. 알림
- 새 영상, 댓글·반응, 일정 알림을 유형별 설정
- 개인별 요일·시간대 무음 설정
- 자정을 넘는 시간대와 사용자 시간대 변경 고려
- 기록을 재촉하는 알림은 기본 비활성화
- 무음 중 알림 처리 방식을 구체적으로 정의

3. 공유 일정
- 개인 일정은 선택적으로 공유
- 공동 일정 생성·수정·삭제
- 하루 목록과 월간 캘린더
- 제목, 시작·종료 시간, 종일 여부, 장소 메모, 설명
- 각자의 일정 알림 설정
- 기념일
- 공동 일정 수정 충돌 처리

4. 공동 목록
- 장보기 목록과 일반 체크리스트
- 항목명, 수량, 메모, 담당자, 완료 여부
- 두 사람의 변경 사항 동기화
- 중복 요청과 동시 수정 처리

5. 여행
- 여행명, 기간, 장소 메모
- 날짜별 일정과 준비물 목록
- MVP에서 지도 경로 최적화, 예약 연동, 비용 정산 제외

6. 일기
- 제목, 본문, 날짜, 감정, 선택적 사진
- 기본 비공개
- 사용자가 명시적으로 선택한 일기만 상대에게 공개
- 공개 철회 시 상대의 접근 차단

7. 문장과 단어
- 책 구절 또는 단어 직접 입력
- 책 제목, 저자, 페이지, 내 생각, 태그
- 개인 보관 또는 상대와 공유
- 검색과 즐겨찾기
- MVP에서 OCR과 외부 도서 API 제외

[정보 구조]
하단 탭:
- 오늘: 영상 타임라인, 오늘의 공동 일정, 촬영 진입
- 일정: 하루 일정, 캘린더, 여행
- 함께: 장보기, 공동 할 일, 준비물
- 기록: 일기, 문장·단어, 날짜별 영상 모음
프로필/설정:
- 연결 상태, 초대, 기념일, 알림, 연결 해제, 계정 삭제

- 중요한 제품 결정만 묶어서 질문하고 나머지는 진행해라.

- 특히 동시 초대 수락, 연결 해제, 비공개 기록 유출, 업로드 실패를 다뤄라.
